# Günce

A personal iPhone app for work that keeps getting interrupted: capture in seconds, **park** a
task with a one-line note on where you left off, and **resume** from that note later.

- SwiftUI (iOS 26), Lock Screen widgets, Live Activities, calendar sync, notifications
- Supabase backend with Row Level Security
- Claude can read and write tasks through an MCP connector
- Every push to `main` builds on GitHub Actions and ships to TestFlight

Setup: [docs/SETUP.md](docs/SETUP.md). Contributor and AI guidance: [CLAUDE.md](CLAUDE.md).
